# Comandos Consola :computer:

Antes de comenzar, veamos algunos comandos que podemos usar en **Consola** para realizar distintas funciones importantes:

- **`ls:`** Sirve para ver todos los archivos que hay dentro del directorio en que te encuentres navegando. 

  <img src = Images/ConsoleCommands/ls_command.png height = 200 width = 400>  

- **`cd + Directorio:`** Sirve para acceder a un Directorio dentro de el Usuario en donde estés trabajando. Usa `cd ..` para retroceder una carpeta.  

  <img src = Images/ConsoleCommands/cd_command.png height = 200 width = 400>  

- **`ni + NombreArchivo:`** Sirve para crear un archivo de cualuier tipo dentro del directorio donde te encuentras; no necesariamente será un archivo que puedas abrir.[^1]  

  <img src = Images/ConsoleCommands/ni_command.png height = 200 width = 400>  

- **`pwd:`** Te devuelve el directorio en donde te encuentras.  

  <img src = Images/ConsoleCommands/pwd_command.png height = 200 width = 400>  

- **`mkdir + NombreCarpeta:`** Sirve para crear una carpeta en el directorio en que te encuentras.[^2]  

  <img src = Images/ConsoleCommands/mkdir_command.png height = 200 width = 400>  

- **`clear:`** Limpia la consola de todos los comandos que hayas hecho anteriormente.  

  <img src = Images/ConsoleCommands/clear_command.png height = 200 width = 400>  

[^1]: Se creó un documento holamundo.py dentro de la carpeta Git_Github
[^2]: Se creó una carpeta Codigo dentro de la carpeta Images

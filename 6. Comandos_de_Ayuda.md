# Comandos de Ayuda :sos:

Tenemos también aqui algunos comandos que no son los que sirven para realizar el guardado de versiones pero si son útiles para ayudarnos a realizar las tareas de manera efectiva y rapida.

- **`git config --global alias."Nombre" "Comando":`** Los Alias sirven para guardar con nombre propio un comando específico. Sirve si usas mucho un comando con varias especificiaciones y no deseas colocarlo cada vez. Puedes verlos en la configuracion de git que se encuentra por lo general dentro de la carpeta de tu Usuario.[^1]  

<img src = Images/GitCommands/git_alias.png height = 260 width = 550>  

- **`git mv "NombreActual" "NombreNuevo":`** Este comando sirve para renombrar un archivo de tu proyecto, sirve debido a que en algunas ocasiones no se detecta el cambio de mayúsculas a minúsuculas de los nombres de los archivos.  

<img src = Images/GitCommands/git_mv.png height = 260 width = 550>  

[^1]: El comando **`ver`** fue definido como un Alias, dentro de la git config se puede ver el verdadero comando que es: **`log --graph --decorate --all --oneline`**
